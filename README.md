# Full Stack Development — Complete Guide

## What is Full Stack?

Full Stack Development means building and managing the entire application:

- Frontend (UI / Client side)
- Backend (Server / Business logic)
- Database (Data storage)
- DevOps (Deployment & infrastructure)

A Full Stack Developer can work across all layers of a software system.

# Architecture Overview

User → Frontend → Backend API → Database → Response → Frontend

3) Database checks credentials
